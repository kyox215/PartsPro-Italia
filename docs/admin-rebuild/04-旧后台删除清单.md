# 04 - 旧后台删除清单

## 删除原则

不做一次性清空。每个模块完成新实现、验收命令通过、人工场景通过后，才删除对应旧代码。

## 当前迁移期保留

- `src/components/admin/*`：现有页面仍在引用，第一阶段只停止继续扩散。
- `src/app/[locale]/admin/*` 旧页面：逐页替换，不新建 `/admin-v2`。
- 旧 admin lib 与旧 API：新 service 未覆盖前保留。

- `src/app/[locale]/admin/layout.tsx`
- `src/components/admin/admin-shell.tsx`

- layout 改用 `src/admin/config/nav.ts` 和 `src/admin/ui/admin-shell-client.tsx`。

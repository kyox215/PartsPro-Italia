# 01 - Ant Design 后台 UI 设计系统

## 基础原则

- 使用真实 Ant Design 组件，不继续扩散旧自研卡片风格。
- 后台第一屏直接进入业务操作，不做营销式 hero。
- `/zh/admin` 是主体验；`/it/admin` 保留关键导航、状态和错误文案。
- Ant Design App Router 接入使用 `@ant-design/nextjs-registry`。

## 主题

```ts
token: {
  colorPrimary: "#1677ff",
  borderRadius: 8,
  wireframe: false
}
```

颜色语义：

- primary：主操作、当前导航、关键链接。
- green：成功、完成、已发布、已收款。
- orange/gold：待处理、待确认、低库存。
- red：失败、取消、退款、危险操作。
- blue：处理中、已发货、审核中。
- purple：预购、在途、锁库。

## 后台 Shell

后台 shell 必须包含：

- 左侧主菜单，支持分组和二级菜单。
- 顶部全局搜索，搜索客户、订单、SKU。
- 顶部用户信息、通知入口、返回商城入口。
- 根据当前路径生成选中菜单和面包屑。
- 移动端使用 Drawer 菜单。
- 页面内容区不再包多层装饰卡片。

## 页面结构

每个后台页面按以下顺序组织：

1. `AdminPageHeader`：标题、说明、主操作、次操作、返回/页面 tab。
2. `AdminFilterBar`：关键词、核心状态、日期范围、高级筛选、重置。
3. `AdminTable`：标准分页、排序、批量操作、行操作、空状态。
4. `AdminFormModal` / `Drawer`：创建、编辑、详情。
5. `AdminResult` / `AdminToast`：空、错、无权限、成功反馈。

## 表单规范

表单必须声明字段结构：

```ts
type AdminFormField = {
  name: string;
  label: string;
  type: "text" | "number" | "money" | "select" | "date" | "textarea" | "upload";
  required?: boolean;
  options?: Array<{ label: string; value: string }>;
  placeholder?: string;
  help?: string;
  permission?: string;
};
```

布局规则：

- 默认两列。
- 长文本、上传、复杂说明占满整行。
- 提交按钮在弹窗 footer 或页面固定 action bar。
- 保存失败必须显示字段级错误和页面级错误。
- 危险 mutation 必须使用确认弹窗。

## 表格规范

表格只消费标准响应：

```ts
type AdminListResponse<T> = {
  items: T[];
  total: number;
  page: number;
  pageSize: number;
};
```

列声明必须包含：

```ts
type AdminTableColumn = {
  key: string;
  title: string;
  width?: number;
  sortable?: boolean;
  permission?: string;
};
```

行操作固定顺序：查看、编辑、状态变更、更多。批量操作只在选中行后出现。

## 筛选规范

第一行筛选：

- 关键词。
- 核心状态。
- 日期范围。
- 查询和重置按钮。

第二行筛选：

- 品牌、型号、价格组、支付方式、库存来源、客户分组等高级字段。

筛选状态必须进入 URL query，方便刷新、分享和返回。

## 弹窗与抽屉

- 新建/编辑短表单：Modal。
- 订单详情、客户详情、SKU 详情：Drawer 或独立详情页。
- 删除、退款、释放库存、取消订单：Confirm Modal。
- 按钮顺序：取消在左，主操作在右；危险操作用红色主按钮。
- 所有弹窗必须有标题、说明、错误区和提交 loading。

## 状态反馈

统一组件：

- `AdminStatusTag`：订单、付款、库存、客户状态。
- `AdminResult`：空数据、无权限、系统异常。
- `AdminToast`：保存、导入、批量操作结果。
- `AdminConfirmModal`：危险动作确认。
- `ProgressSteps`：订单、导入、退款流程。

## 禁止项

- 后台页面堆多个无边界大卡片。
- 每个模块单独发明按钮、状态标签、筛选样式。
- 技术调试文案进入普通业务页面。
- 移动端强塞完整宽表格。

# 02 - 后台业务状态机

## 总体原则

订单状态、付款状态、履约状态必须分离；任何动作都通过状态机判断是否允许，再进入 service、RPC、audit log。页面只展示允许动作，不在组件里硬编码业务跳转。

## 订单状态

状态：

- `draft`：草稿，仅系统内部或未完成创建。
- `pending_payment`：待付款。
- `confirmed`：已确认，可备货。
- `processing`：处理中，已进入仓库流程。
- `completed`：完成。
- `cancelled`：取消。
- `refunded`：全额退款后关闭。

主动作：

- `create_order`：创建订单并锁库。
- `confirm_order`：财务或系统确认订单进入处理。
- `start_processing`：仓库开始备货。
- `complete_order`：履约结束。
- `cancel_order`：取消并释放未履约库存。
- `refund_order`：退款并写入财务记录。

## 付款状态

状态：

- `unpaid`：未付款。
- `pending_manual_review`：现金/转账待确认。
- `authorized`：卡支付授权或待捕获。
- `paid`：已付款。
- `partially_refunded`：部分退款。
- `refunded`：全额退款。
- `failed`：付款失败。

允许动作：

- `submit_payment_proof`：客户或员工提交付款凭证。
- `confirm_cash`：财务确认现金。
- `confirm_bank_transfer`：财务确认转账。
- `confirm_card_payment`：Stripe 成功回调或管理员校正。
- `mark_payment_failed`：标记失败。
- `refund_payment`：按金额退款。

权限：

- `finance:write` 才能确认现金、转账、退款。
- `orders:write` 可发起订单操作，但不能越权修改财务结果。

## 履约状态

状态：

- `not_started`：未开始。
- `picking`：备货中。
- `ready_for_pickup`：可自提。
- `shipped`：已发货。
- `delivered`：已送达或自提完成。
- `blocked`：异常阻塞。

允许动作：

- `start_picking`：仓库备货。
- `mark_ready_for_pickup`：自提准备完成。
- `ship_order`：填写物流并发货。
- `mark_delivered`：完成履约。
- `block_fulfillment`：缺货、地址、付款异常阻塞。

权限：

- `inventory:write` 或 `orders:write` 可推进仓库履约。
- 仓库角色只显示到货、缺货、流水、备货和发货相关动作。

## 库存状态

字段语义：

- `stock_on_hand`：现货库存。
- `stock_reserved`：现货锁定。
- `incoming_quantity`：在途数量。
- `incoming_reserved`：在途锁定。
- `available_to_sell`：可售现货。
- `available_to_preorder`：可预购在途。

库存动作：

- `reserve_stock`：下单锁现货或预购。
- `release_reservation`：取消、超时、支付失败释放。
- `receive_stock`：到货入库。
- `mark_missing`：缺货登记。
- `manual_adjust`：管理员手动调整。
- `allocate_preorder`：到货后分配预购订单。

规则：

- 所有库存变更必须生成 movement。
- 所有手动变更必须写 audit log。
- 手动调整只允许 `inventory:write` 且管理员/经理可见。

## 客户状态

状态：

- `lead`：潜在客户。
- `active`：正常客户。
- `wholesale`：批发客户。
- `suspended`：暂停。
- `archived`：归档。

动作：

- `approve_wholesale`：批准批发。
- `change_price_group`：调整价格组。
- `suspend_customer`：暂停账号。
- `restore_customer`：恢复账号。
- `archive_customer`：归档。
- `add_note`、`add_tag`、`create_task`：客户跟进。

权限：

- `customers:read` 查看客户。
- `customers:write` 修改客户资料、标签、备注和任务。
- `staff:write` 或更高权限才可绑定员工账号。

## 退款状态

状态：

- `requested`：已申请。
- `reviewing`：审核中。
- `approved`：已批准。
- `rejected`：已拒绝。
- `processing`：退款处理中。
- `completed`：退款完成。
- `failed`：退款失败。

规则：

- RMA 不恢复。
- 售后原因、退款金额、退款方式、凭证归入订单与财务。
- Stripe 退款和手动退款必须分开记录。
- 退款会联动付款状态、订单状态和订单 timeline。

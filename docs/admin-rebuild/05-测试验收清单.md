## Ant Design UI 验收

- 桌面 `/zh/admin` 可访问，左侧菜单、顶部搜索、用户信息、返回商城可用。
- 移动端 `/zh/admin` 可访问，菜单 Drawer 可打开关闭。
- `/it/admin` 可访问，关键导航与状态文案可读。
- 列表页有统一筛选、表格、分页、空状态。
- 表单弹窗有 loading、成功、错误、字段校验。
- 危险操作必须出现确认弹窗。
- 无权限页面使用统一错误状态。

## 权限验收

账号类型：

- owner：全部菜单、按钮、API。
- warehouse：库存、到货、缺货、流水、备货/发货。
- finance：付款确认、退款、财务筛选、订单只读/必要操作。
- support：客户查看、备注、标签、跟进任务、订单协作。

检查项：

- 菜单隐藏无权限入口。
- 按钮隐藏或禁用无权限动作。
- API mutation 无权限返回 403。
- 审计日志记录 actor、action、target、metadata。

## 数据验收

- 旧数据可读。
- 新操作写入新结构。
- 新旧字段语义一致。
- 旧 RPC/API 移除前已有新链路覆盖。
- 库存、订单、付款跨表动作事务一致。
- `admin_v2_*` RPC 返回 `{ ok, data/error }` 标准响应。
- `admin_v2_*` RPC 只授予 `service_role` 执行权限。
- 每个 v2 RPC 替换动作必须验证成功路径、校验失败路径、事务回滚路径。
- 应用 `supabase/migrations/20260522000405_admin_v2_order_rpc.sql` 后，先在未设置 `ADMIN_ORDER_V2_RPC_ENABLED` 时跑一遍旧路径回归。
- 设置 `ADMIN_ORDER_V2_RPC_ENABLED=true` 后，验证 Stripe checkout session 回写、订单时间线追加、订单状态更新三条低风险 v2 路径。
- 应用 `supabase/migrations/20260522001121_admin_v2_order_payment_rpc.sql` 后，验证现金确认、转账确认、付款凭证记录三条付款 v2 路径，并确认客户通知仍写入 `notification_events`。
- 应用 `supabase/migrations/20260522001416_admin_v2_order_shipment_rpc.sql` 后，验证无追踪号只更新时间线、有追踪号进入 `shipped`、客户通知仍写入 `notification_events`。
